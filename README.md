# My Gacha Game

This project is a fully static web game. It does not require a backend server and can be hosted on GitHub Pages, Netlify, Vercel, or any other static host.

## Deploy to GitHub Pages

1. Push this folder to a GitHub repository.
2. Open the repository on GitHub.
3. Go to Settings > Pages.
4. Set the source to GitHub Actions.
5. The workflow in [.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml) will publish the site automatically.

## Run locally

Open [index.html](index.html) in a browser, or serve the folder with a simple static server.
